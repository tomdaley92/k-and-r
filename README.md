# k-and-r

Compile just the `hello_world.c` program:
```bash
make hello_world
```

And then run it...
```bash
./hello_world
```

Or you can compile all the programs at once:
```bash
make
```

And then run any one of them...
```bash
./symbolic_constants
```

Remove any object files and executables from workspace
```bash
make clean
```
