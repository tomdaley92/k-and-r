# k-and-r

Code samples from [_**The C Programming Language** (2nd Edition)_](https://github.com/AzatAI/cs_books/blob/master/The.C.Programming.Language.2nd.Edition.pdf)

<br>

### _You will need_...
>GNU Make<br>
>GNU C Compiler

<br>

1. You can compile each program individually.

    ```bash
    make hello_world
    ```

1. Or you can compile all of the programs at once.

    ```bash
    make
    ```

1. And then you can run any one of them.

    ```bash
    ./hello_world
    ```

1. Clean up by deleting created objects and executables.

    ```bash
    make clean
    ```
